# 📊 Sales Performance Dashboard — Excel

## Project Overview

An interactive Sales Performance Dashboard developed using Microsoft Excel to analyze sales performance, profitability, regional trends, product performance, and monthly sales trends.

## 🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* PivotCharts
* Power Query
* Excel Formulas
* Slicers
* Conditional Formatting
* Dashboard Design

## 📈 Dashboard Features

* Total Sales KPI
* Total Orders KPI
* Total Profit KPI
* Profit Margin
* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Top 10 Products
* Profitability Analysis
* Interactive Slicers
* Date-based filtering

## 🔍 Data Preparation

The raw sales data was cleaned and prepared using Excel and Power Query.

Tasks included:

* Removing duplicate records
* Handling missing values
* Standardizing date formats
* Checking data consistency
* Creating calculated fields
* Preparing data for PivotTable analysis

## 💡 Key Business Insights

* Identified the highest-performing regions based on sales.
* Compared sales performance across product categories.
* Analyzed monthly revenue trends.
* Identified top-performing products.
* Compared revenue and profitability across categories.
